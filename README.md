# Planejador de Estudos - Residência de Cirurgia Geral 🩺

Um aplicativo web interativo, moderno e responsivo projetado para organizar e acompanhar o progresso de estudos voltados para a residência médica em **Cirurgia Geral**.

Hospedado no GitHub Pages e pronto para uso:
👉 **[Hospedagem Oficial do Projeto](https://ebert-g.github.io/tacoplan-surgery-residency/)**

---

## ✨ Funcionalidades

* **Cronograma Estruturado:** Divisão em blocos de estudo principais:
  * 🔹 **Fundamentos:** Princípios fundamentais antes das especialidades.
  * 🟢 **Trauma:** Diretrizes do ATLS completas.
  * 🟡 **Abdome Agudo:** Diagnósticos diferenciais cruciais.
  * 🟠 **Cirurgia Digestiva:** O coração das provas de residência.
  * 🔴 **Cirurgia Vascular:** Doenças arteriais e venosas.
  * 🟣 **Mama e Tireóide:** Endocrinologia cirúrgica essencial.
  * ⚪ **Simulados:** Retas finais e pearls de prova.
* **Sincronização em Nuvem:** Salvamento automático em segundo plano. As marcações feitas no celular refletem imediatamente no computador ou tablet, sem necessidade de login.
* **Métricas Visuais:** Acompanhamento do progresso geral com gráficos circulares e barras individuais para cada bloco.
* **Design Premium:** Interface otimizada em tema escuro com fontes de alta legibilidade, adaptada para telas de celulares e desktops.

---

## 🛠️ Tecnologias Utilizadas

* **Estrutura:** HTML5 Semântico
* **Estilização:** CSS3 (Variáveis nativas, Flexbox, Grid e animações suaves)
* **Lógica:** JavaScript Vanilla (ES6+)
* **Banco de Dados:** Key-Value API Cloud Persistence (`keyvalue.immanuel.co`)
